# 보고서 형식

이 스킬이 Discord로 보낼 본문을 쓸 때 읽는다. 전송은 `discord-message` 스킬이 맡고, 채널·도구·실패 처리는 그 스킬의 `references/tools.md`에 있다.

예시의 작업명·번호는 형식 설명용 가상 값이다.

---

## 제목 줄

첫 줄은 아래로 고정한다. 여러 저장소가 같은 채널에 보고하므로, 읽는 사람이 이 줄의 종류·저장소·날짜로 메시지를 구분한다.

```
## 📋 <repo> · 2026-01-15 KST
```

📋는 이 보고서의 종류 표시다. 같은 채널에 다른 종류(Issue close·하루 마감)의 보고서가 섞이므로 다른 이모지를 쓰지 않는다.

날짜는 한국 시간 기준이다. `<repo>`는 저장소 이름이고 owner는 뺀다. 저장소들이 모두 같은 계정이라 owner는 구분에 보탬이 없고 제목만 길어진다.

## 본문 모양

- 제목 줄과 본문, 섹션 사이, 섹션 제목과 목록 사이에는 빈 줄을 하나 둔다. 섹션 제목은 `**굵게**`로 쓴다.
- 항목은 `-` 목록으로 쓰고 작업명은 `**굵게**`로 강조한다. 이슈 번호와 링크는 강조하지 않는다.
- 작업명은 Issue 제목에서 종류 접두사(`feat: `, `fix: `, `chore: ` 등)를 뗀 나머지다. 섹션 제목이 이미 카테고리를 보여주므로 접두사는 같은 정보를 반복한다.
- 이모지는 제목과 표시 어휘에만 쓴다. 장식용 구분선이나 인용 블록은 쓰지 않는다.
- 이슈 링크는 `[#번호](<https://...>)`처럼 번호에 건다. 긴 URL을 본문에 따로 표시하지 않고, URL은 꺾쇠로 감싸 미리보기 카드를 억제한다. 관계 안내에서 번호를 다시 언급할 때는 일반 텍스트로 쓴다.
- 표는 쓰지 않는다. Discord에서 렌더링되지 않는다.
- 한 메시지는 2000자 이하로 쓴다. 넘으면 요약해서 줄인다. `discord-message`는 초과한 본문을 보내지 않는다.

## 항목

오늘 목록의 알림이다. 목록은 상태 라벨(`SELECTED`·`IN_PROGRESS`)이 붙은 열린 Issue 전체이고, 원본은 라벨이다. 작업은 사용자가 고른다. 에이전트가 더하거나 빼지 않는다.

항목과 표시 어휘는 `classification.md`가 정한다. 이 절은 그 어휘를 어디에 놓을지만 정한다.

- 섹션은 카테고리이고, 항목이 없는 섹션은 쓰지 않는다. 섹션 순서는 `classification.md` "카테고리", 항목 순서는 "결과 순서"를 따른다.
- 상태 표시는 작업명 뒤에 가운뎃점(`·`)을 앞뒤 공백과 함께 두고 이어 붙인다. 관계 줄과 같은 줄에 두지 않는다.
- 관계 어휘는 항목 바로 아래 줄에 두 칸 들여 쓴다. 열린 직접 선행이 없으면 줄을 생략한다. 일반 선행은 한 줄, 상위 묶음은 `← #19` 다음 줄에 두 칸 더 들여 `└─ #29, #30 남음`을 더해 두 줄이다.
- 상위 묶음이 여러 개면 묶음마다 두 줄을 반복하고, 일반 선행은 한 줄로 묶어 따로 쓴다. 줄 순서는 각 줄 또는 묶음의 첫 번호순이다.
- 역방향 어휘(`🔓 끝내면…`)와 그 항목 자신의 `⬆ 상위…`는 쓰지 않는다. 메시지에는 선행 방향만 둔다.
- 관계 줄의 번호는 일반 텍스트로 쓴다. 링크는 항목 번호에만 건다.
- 관계 줄 아래에 트리나 코드블록을 더하지 않는다.

```
## 📋 <repo> · 2026-01-15 KST

**feature**

- [#101](<https://github.com/<owner>/<repo>/issues/101>) **로그인 폼 유효성 검사**
- [#102](<https://github.com/<owner>/<repo>/issues/102>) **목록 페이지 로딩 상태 표시**
  ← #101
- [#104](<https://github.com/<owner>/<repo>/issues/104>) **인증 오류 메시지 연결** · 🔄 진행 중
  ← #101
- [#105](<https://github.com/<owner>/<repo>/issues/105>) **인증 오류 처리**
  ← #100
    └─ #101, #104 남음

**other**

- [#103](<https://github.com/<owner>/<repo>/issues/103>) **CI 캐시 설정**
```
