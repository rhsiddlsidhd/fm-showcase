# 시스템 경계

앱은 빌드한 정적 파일로 배포한다. 상시 실행되는 서버, 서버 쪽 영속 데이터, 사용자 인증이 없다. 서버 코드는 외부 API를 중계하는 Vercel Functions만 둔다.

## 외부 API

- 키가 필요 없고 CORS를 허용하는 외부 API는 브라우저에서 직접 호출한다.
- 키가 필요하거나 CORS를 막아 둔 외부 API는 Vercel Functions로 중계한다. 별도 서버를 배포하지 않는다([ADR 0001](../../adr/0001-relay-external-api-with-vercel-functions.md)).

## Vercel Functions

- 함수는 루트의 `api/`에 둔다. Vercel이 이 경로를 함수로 배포한다.
- 함수는 외부 API를 중계만 한다. 데이터를 저장하거나 인증을 두지 않는다.
- 함수는 정해 둔 외부 API 주소만 호출한다. 요청받은 주소를 그대로 호출하면 누구나 우리 키로 아무 곳이나 부르는 열린 중계가 된다.
- 외부 API 실패는 호출부에 실패 응답으로 전달하고, 응답에 비밀값을 포함하지 않는다.
- 키는 Vercel 환경 변수에 둔다. 이름에 `VITE_` 접두사를 붙이지 않는다. 붙이면 Vite가 값을 빌드 산출물에 넣는다.
- 로컬에서는 `vercel dev`로 앱과 함수를 함께 띄운다. Vite 개발 서버는 함수를 실행하지 않는다.
- `vercel dev`는 처음 한 번 사람이 Vercel 로그인과 프로젝트 연결을 해야 한다. 에이전트는 이 단계를 대신하지 않고 사용자에게 요청한다.
- 로컬 키는 `.env.local`에 둔다. 커밋 제외는 [`.gitignore`](../../.gitignore)가 정한다.

## 경계를 넘는 변경

아래 중 하나라도 생기는 변경은 경계를 넘는다.

- 외부 API 중계가 아닌 서버 코드
- 서버 쪽에 데이터를 저장하는 것
- 사용자 인증이나 권한
- 다른 시스템이 호출하는 API나 이벤트

경계를 넘는 변경은 구현 전에 사용자가 결정한다. 결정은 [ADR](../spec/adr.md)로 남기고, 이 문서를 그 결정에 맞게 고친다.

## 비밀값

- 브라우저에서 실행되는 코드에는 비밀값을 두지 않는다. 빌드 산출물은 누구나 내려받아 읽을 수 있다.
- 개발 자동화(`scripts/`, `.github/workflows/`)의 비밀값은 GitHub Actions secrets에만 둔다. 개발 자동화는 앱의 경계 밖이다.
