# 테마 규칙

디자인 토큰은 공통 토큰과 페이지 변수를 함께 이른다. 색, 글자, 여백과 간격, 모서리, 그림자와 효과, 가로세로 비율을 포함한다. 움직임 값은 [애니메이션 규칙](animation.md)을 따른다.

## 구현 방식

- 도메인 테마는 슬라이스 범위에서 CSS 변수를 재정의해 구현한다. shadcn 컴포넌트와 Tailwind 유틸리티를 도메인마다 그대로 쓸 수 있기 때문이다.
- `/`도 다른 도메인과 같은 방식을 쓴다.
- `src/app/styles/index.css`는 기본값이다. 도메인 디자인을 위해 고치지 않는다. 고치면 그 공통 토큰을 재정의하지 않은 모든 도메인이 바뀐다.
- 디자인 토큰으로 표현할 수 없는 스타일에만 CSS Modules를 쓴다.
- `theme.css`에는 `@theme`을 쓰지 않는다. 이 파일은 Tailwind 진입 CSS가 아니어서 처리되지 않는다.

## 산출 규칙

| 항목 | 규칙 |
| --- | --- |
| 파일 | `src/pages/<슬라이스>/ui/theme.css`. 스타일은 `ui` 세그먼트 소관이다 |
| 범위 클래스 | `.theme-<슬라이스>` |
| 적용 | 슬라이스 공통 최상위 요소에 한 번 붙인다 |
| 최상위 요소 | `bg-background text-foreground min-h-dvh`를 함께 쓴다. `body`의 배경과 글자색은 테마를 따르지 않는다 |
| import | 슬라이스 `index.tsx`에서 가져온다 |
| 페이지 변수 | `--<슬라이스>-<이름>` |

## 산출 순서

1. 도메인 기준에서 디자인 토큰 값을 정한다. 챌린지는 원본에서 뽑는다.
2. 같은 의미의 공통 토큰(`--background`, `--primary`, `--radius` 등)에 대응시켜 재정의한다.
3. 대응되는 공통 토큰이 없는 값은 페이지 변수로 둔다.
4. 재정의하지 않는 공통 토큰은 전역 값을 그대로 쓴다.

## 사용 규칙

- 컴포넌트는 디자인 토큰을 공통 토큰 유틸리티(`bg-primary`)나 페이지 변수(`bg-(--<슬라이스>-<이름>)`, `p-(--<슬라이스>-<이름>)`, `text-(length:--<슬라이스>-<이름>)`)로만 쓴다.
- 컴포넌트에 값을 직접 쓰지 않는다(`bg-[#1a2b3c]`). 값이 `theme.css` 밖으로 흩어지면 비교와 수정이 어려워진다.
- `--spacing`은 재정의하지 않는다. `p-4` 같은 유틸리티와 shadcn 부품까지 바뀐다.

## 다크 모드

- `.dark`는 범위 클래스와 같은 요소에 붙인다. 도메인을 벗어나면 함께 사라져 다른 도메인으로 새지 않는다.
- 다크 모드 값은 `.theme-<슬라이스>.dark`에 쓴다.
- 다크 모드에서 쓰는 공통 토큰은 이 selector에 모두 쓴다. 쓰지 않은 공통 토큰은 `.dark`의 전역 값이 될 수 있다.
- 토글이 있는 도메인은 최상위 요소를 `ui/`의 동작 컴포넌트가 맡는다.

## 폰트

- 폰트는 `@fontsource` 패키지로 설치하고 슬라이스 `index.tsx`에서 가져온다.
- 범위 클래스에 `--font-sans`와 `font-family`를 함께 쓴다. `font-sans` 유틸리티는 값이 고정되어 있고, `font-heading`은 변수를 따른다.

## Portal

- `body`로 렌더링되는 부품은 범위 밖이다. 콘텐츠 요소의 `className`에 범위 클래스를 넘긴다.
- 다크 모드이면 `dark`도 함께 넘긴다.
