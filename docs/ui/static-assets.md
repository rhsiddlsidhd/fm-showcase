# 정적 자산 규칙

이미지·아이콘처럼 폰트가 아닌 정적 자산을 다루는 규칙이다. 디자인 토큰 값은 [테마 규칙](theme.md)을, 폰트는 [테마 규칙의 글꼴](theme.md#글꼴)을 따른다.

## 산출 위치

| 항목 | 규칙 |
| --- | --- |
| 위치 | `public/<슬라이스>/` |
| 참조 | 슬라이스 `ui/assets.ts`의 절대경로 상수 (예: `ICON_SEARCH`) |

- 경로 문자열은 `ui/assets.ts`에만 쓴다. 경로를 조립하는 규칙(파일 이름 패턴 등)도 이 파일이 맡고, `model`은 자산을 가리키는 값(예: 날씨 종류)만 돌려준다. 경로가 바뀌어도 한 파일만 고치면 된다.
- CSS 배경 이미지는 컴포넌트가 상수를 `style`의 CSS 변수로 넘기고 `bg-(image:--…)`로 읽는다. Tailwind는 클래스 문자열을 빌드 시점에 읽으므로 TS 상수를 클래스에 넣을 수 없다.
- 테스트는 경로 문자열로 검증한다. 상수를 가져오면 상수가 틀려도 테스트가 같이 통과한다. 상수 import 금지는 `eslint.config.js`가 판정한다.
- 슬라이스로 네임스페이싱해 챌린지끼리 파일 이름이 겹쳐도 충돌하지 않게 한다.
- `public/`은 Vite가 그대로 복사한다. 캐시버스팅이 없고, import하지 않아도 그대로 배포된다.
- 앱 전역으로 쓸 자산(예: favicon)은 챌린지 하나의 자산을 전역으로 승격하는 결정이 된다. 그 챌린지의 설계안에 묻어두지 않고 별도로 결정한다.
