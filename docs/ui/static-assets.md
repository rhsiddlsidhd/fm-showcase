# 정적 자산 규칙

이미지·아이콘처럼 폰트가 아닌 정적 자산을 다루는 규칙이다. 디자인 토큰 값은 [테마 규칙](theme.md)을, 폰트는 [테마 규칙의 폰트](theme.md#폰트)를 따른다.

## 산출 위치

| 항목 | 규칙 |
| --- | --- |
| 위치 | `public/<슬라이스>/` |
| 참조 | 절대경로 문자열 (예: `"/weather-app/images/icon-sunny.webp"`) |

- 슬라이스로 네임스페이싱해 챌린지끼리 파일 이름이 겹쳐도 충돌하지 않게 한다.
- `public/`은 Vite가 그대로 복사한다. 캐시버스팅이 없고, import하지 않아도 그대로 배포된다.
- 앱 전역으로 쓸 자산(예: favicon)은 챌린지 하나의 자산을 전역으로 승격하는 결정이 된다. 그 챌린지의 설계안에 묻어두지 않고 별도로 결정한다.
