# 정적 자산 규칙

이미지·아이콘처럼 폰트가 아닌 정적 자산을 다루는 규칙이다. 디자인 토큰 값은 [테마 규칙](theme.md)을, 폰트는 [테마 규칙의 글꼴](theme.md#글꼴)을 따른다.

## 산출 위치

| 항목 | 규칙 |
| --- | --- |
| 위치 | `public/<슬라이스>/` |
| 참조 | 루트 기준 절대경로 (예: `/weather-app/images/icon-search.svg`) |

- 경로를 상수로 모을지, 어느 파일에 둘지는 슬라이스가 정한다. 편의 수단이라 규칙으로 두지 않는다.
- CSS 배경 이미지는 다른 스타일 값처럼 [값 배치](theme.md#값-배치)에 따라 둔다. 일회성이면 컴포넌트의 arbitrary value(`bg-[url(/weather-app/images/bg-today-small.svg)]`)로 쓴다.
- 테스트는 경로 문자열로 검증한다. 상수를 가져오면 상수가 틀려도 테스트가 같이 통과한다. 슬라이스 `ui/assets`의 import 금지는 `eslint.config.js`가 판정한다.
- 슬라이스로 네임스페이싱해 챌린지끼리 파일 이름이 겹쳐도 충돌하지 않게 한다.
- `public/`은 Vite가 그대로 복사한다. 캐시버스팅이 없고, import하지 않아도 그대로 배포된다.
- 앱 전역으로 쓸 자산(예: favicon)은 챌린지 하나의 자산을 전역으로 승격하는 결정이 된다. 그 챌린지의 설계안에 묻어두지 않고 별도로 결정한다.
