# 반응형 규칙

- 화면 폭 경계는 Tailwind 기본 경계(`sm`, `md`, `lg`, `xl`, `2xl`)를 모든 도메인에서 쓴다. 도메인끼리 같은 이름으로 비교할 수 있고, 근거 없는 경계를 지어내지 않는다.
- 경계는 디자인 토큰이 아니다. 설계안은 숫자 대신 경계 이름으로 가리킨다.
- 원본 디자인의 화면 폭은 화면을 비교할 폭이지 경계가 아니다.

## 챌린지 기준

- 챌린지 과제가 기본 경계와 다른 반응형 기준을 주면 그 도메인만 그 기준을 쓴다. 설계안에 기준과 출처를 쓴다.
- 구현은 `min-[<값>px]:` 같은 임의 경계로 한다. 전역 CSS는 고치지 않는다([테마 규칙](theme.md#구현-방식)).
