# 결정 기록 (ADR)

확정한 결정과 그 이유를 루트 `adr/`에 쌓는다. `docs/`는 현재 기준을, ADR은 고치지 않는 기록을 담는다.

## 쓰는 조건

- 사용자가 확정했고, 대안을 둘 이상 비교했고, 재검토 조건이 있는 결정만 쓴다.
- 작업 중 초안과 검토 메모는 `.sdd/`에 둔다.

## 파일

- `adr/NNNN-<kebab-case-결정>.md`. 번호는 `0001`부터 매기고 다시 쓰지 않는다. 링크가 다른 결정을 가리키게 된다.
- 한 파일에 결정 하나만 쓴다.

## 섹션

순서대로 쓴다. 분량은 권장 범위다. 상한을 넘으면 결정이 둘인지 먼저 확인하고 나눈다.

| 섹션 | 쓰는 것 | 하한 | 상한 |
| --- | --- | --- | --- |
| 상태 | `채택 \| 대체됨 (NNNN)` 중 하나 | 1줄 | 1줄 |
| 배경 | 결정이 필요했던 문제와 근거 링크 | 1문장 | 3문장 |
| 비교한 대안 | 표 `대안 \| 버린 이유`. 버린 이유는 행마다 1문장 | 1행 | 3행 |
| 결정과 근거 | 결정 1문장 + 근거 불릿 | 근거 1개 | 근거 3개 |
| 재검토 조건 | 결정을 다시 볼 조건 불릿 | 1개 | 2개 |

- 쓰지 않는 것: 날짜(git 이력), 현재 규칙(`docs/`), 구현 경위(PR).
- 대안과 근거는 출처(Issue, PR, 사용자 확인)가 있는 것만 쓴다. 없으면 [`(미결정)`](README.md#작성-규칙)으로 둔다.

## 변경

- 본문은 고치지 않는다. 결정이 바뀌면 새 ADR을 쓰고 옛 ADR은 상태만 `대체됨 (NNNN)`으로 바꾼다.
- 결정에서 나온 `docs/` 규칙은 그 ADR을 링크한다. 대안 비교를 `docs/`에 다시 쓰지 않는다.
