# API 명세서

API 명세서는 도메인이 부르는 API의 요청과 응답을 구현 전에 정한 설계안이다. 슬라이스가 외부 API나 루트 `api/`의 함수를 부를 때만 `.sdd/<슬라이스>/api-spec.md`에 둔다.

## 섹션

API 하나마다 아래 섹션을 순서대로 쓴다.

| 섹션 | 쓰는 것 |
| --- | --- |
| 호출 대상 | 외부 API 주소와 문서 링크, 경유(`브라우저 직접 \| Vercel Functions`), 관련 요구사항 ID |
| 요청 | 메서드, 경로, 파라미터. Vercel Functions를 거치면 앱 → 함수, 함수 → 외부 API를 각각 쓴다 |
| 응답 | 쓰는 필드와 예시 |
| 오류와 재시도 | 오류마다 앱이 받는 실패 값, 재시도 여부 |
| fixture | 성공과 실패마다 하나씩, 그 형태 |

## 작성 기준

- 경유는 [시스템 경계](../architecture/boundary.md#외부-api)로 정한다.
- 응답 예시는 실제 응답을 확인한 근거(문서 링크나 확인 방법)를 함께 쓴다. 근거가 없으면 [`(미결정)`](README.md#작성-규칙)으로 둔다.
- 응답 필드는 앱이 쓰는 것만 쓴다.
- 실패는 throw가 아니라 실패 값으로 쓴다. fixture는 테스트의 [`api/` 계약](../testing/test-boundaries.md#api-계약)이 그대로 쓴다.
- 앱 안에서 쓰는 형태로 바꾸는 규칙은 [데이터 모델](data-model.md)에 쓴다.
