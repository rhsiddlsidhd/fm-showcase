# 데이터 모델

데이터 모델은 도메인이 다루는 데이터의 형태를 구현 전에 정한 설계안이다. 슬라이스가 데이터 형태를 정의할 때만 `.sdd/<슬라이스>/data-model.md`에 둔다.

## 섹션

아래 순서로 쓴다.

| 섹션 | 쓰는 것 |
| --- | --- |
| 엔터티와 관계 | 엔터티 목록, 엔터티 사이의 관계 |
| 필드 | 엔터티마다 표 `필드 \| 타입 \| 필수 \| 허용 값` |
| 제약 | 식별자, 유일성, 순서 |
| 출처 | 데이터가 오는 곳(정적 파일, API 응답, URL 쿼리)과 앱의 형태로 바꾸는 규칙 |
| 예시 | 엔터티마다 하나 |

## 작성 기준

- 허용 값이 닫힌 목록이면 모두 쓴다. 순서가 의미를 가지면 그 순서로 쓴다.
- API 응답의 원래 형태는 [API 명세서](api-spec.md)에 쓰고, 여기에는 앱이 쓰는 형태만 쓴다.
- 브라우저 저장소나 URL 쿼리에 남기는 값은 출처에 그 키와 형식을 쓴다.
