# 면접 문항

외부에서 받은 면접 문항지 하나를 동결해 두는 디렉토리다. 문항에는 저장소의 산출물로 답하는 것과 개발자가 직접 답하는 것이 섞여 있고, 앞의 것만 프로젝트 README의 [증거](../../README.md#증거)로 채점한다.

이 README는 인덱스다. 본문은 아래 문서에 둔다.

## 문서

| 문서                             | 읽는 조건                      | 다루는 내용                          |
| -------------------------------- | ------------------------------ | ------------------------------------ |
| [`questions.md`](./questions.md) | 채점 기준이 무엇인지 확인할 때 | 외부에서 온 면접 30개 문항. 동결한다 |

## 규칙

- 문항 본문과 번호를 수정하지 않는다. 외부 기준을 내가 고치면 채점의 의미가 사라진다.
- 체크박스를 두지 않는다. 내가 채점표에 체크하면 자기 채점이 된다.
- 이 디렉토리에는 문항지만 둔다. 답, 문항별 대응표, 문항 분류표를 여기에 모으면 저장소 대신 이 문서가 채점 대상이 된다.
- 문항은 답의 출처로 나눈다. 기여, 검증, 테스트, 오류 대응처럼 실제로 일어난 일을 묻는 문항은 산출물이 답한다. 가정, 가치 판단, 의견을 묻는 문항은 개발자가 답한다.
- 산출물이 답하는 문항의 답은 README, 테스트, 커밋, CI 기록 같은 산출물 자체에 남긴다. 채점은 저장소만 열어본 사람이 한다.
- 개발자가 답하는 문항의 답을 따로 쓰지 않는다. 그 판단이 실제로 쓰인 문서의 이유 문장으로만 남긴다. 답만 모은 문서는 검증할 수 없는 자기 서술이다.
- 판단이 쓰인 자리가 없는 문항은 저장소에 답하지 않는다.
- 기준이나 이유를 묻는 문항은 기준과 그 적용 기록을 산출물로 남기고, 기준을 고른 이유는 그 기준이 적힌 문서에 함께 쓴다.
