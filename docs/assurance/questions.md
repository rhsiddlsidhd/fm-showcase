# 면접 문항지

AI를 써서 만든 코드를 두고 면접관이 지원자에게 묻는 30개 문항이다. 외부에서 온 채점표이므로 **이 저장소에서 문항 본문과 번호를 수정하지 않는다.** 번호는 다른 문서가 문항을 가리키는 참조 키다.

- 성격: 채점표. 이 프로젝트의 목표를 정의하지 않는다. 목표는 [프로젝트 README](../../README.md)가 정의하고, 이 문항지는 그 목표가 달성됐는지를 외부 기준으로 채점한다.
- 채점 주체: 저장소를 직접 열어본 사람. 지원자가 자리에서 보충 설명할 기회가 없다고 가정한다.
- 체크박스를 두지 않는다. 내가 외부 채점표에 체크하면 자기 채점이 된다.
- 문항별로 저장소의 어디가 답하는지는 [`answers.md`](./answers.md)가 가리킨다.
