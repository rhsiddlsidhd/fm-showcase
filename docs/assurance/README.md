# 신뢰 근거

AI를 써서 만든 코드를 외부 채점표로 채점하는 디렉토리다. 어떤 증거가 있고 무엇이 없는지는 [프로젝트 README](../../README.md)의 증거 절이 정의하고, 여기는 그 증거가 면접 문항에 답하는지를 가리킨다.

이 README는 인덱스다. 본문은 아래 문서에 둔다.

## 문서

| 문서                             | 읽는 조건                                                                | 다루는 내용                                                       |
| -------------------------------- | ------------------------------------------------------------------------ | ----------------------------------------------------------------- |
| [`questions.md`](./questions.md) | 채점 기준이 무엇인지 확인할 때                                           | 외부에서 온 면접 30개 문항. 동결한다                              |
| [`answers.md`](./answers.md)     | 문항에 답하는 저장소 위치를 찾거나, 산출물이 바뀌어 포인터를 고칠 때     | 문항 번호 → 저장소 경로 대응표. 근거 문항과 입장 문항을 나눠 둔다 |

## 규칙

- 문항지는 이 프로젝트의 목표가 아니라 채점표다. 목표는 [프로젝트 README](../../README.md)가 정의하고, 채점은 저장소만 열어본 사람이 한다.
- 문항 본문과 번호를 수정하지 않는다. 외부 기준을 내가 고치면 채점의 의미가 사라진다.
- 체크박스를 두지 않는다. 내가 채점표에 체크하면 자기 채점이 된다.
- 이 디렉토리는 답을 보유하지 않는다. 포인터만 둔다. 답 본문은 README, 테스트 전략, 커밋, CI 기록 같은 제 자리에 있어야 한다.
- `answers.md`의 `없음`은 백로그가 아니다. 작업 순서는 README의 목표가 정한다.
