# 0003. 기준 관리. 설정·검증 코드 우선

## Status

대체됨 (0006)

## Context

에이전트가 따라야 할 기준을 문서에만 두면 지켰는지를 기계가 판정하지 못한다. 반면 테스트의 품질처럼 의미 판단이 필요한 기준은 코드로 표현할 수 없다 (출처: 사용자 확인).

## Decision

- 기계로 판정할 수 있는 기준은 설정이나 검증 코드로 올리고, 의미 판단이 필요한 기준만 이유와 함께 `docs/`에 둔다.

- 에이전트가 따를 기준의 준수 여부를 판정해야 하는 문제를 해결해야 했다.
  설정·검증 코드 우선을 택하고 모든 기준을 문서로, 모든 기준을 코드로는 택하지 않았다.
  CI의 결정론적 강제와 문서 분량 축소를 얻기 위해서이며, 설정·검증 코드 유지 비용과 의미 판단 영역의 미보장을 받아들인다.

## Consequences

| 선택지                  | 얻는 것                              | 잃는 것                                             |
| ----------------------- | ------------------------------------ | --------------------------------------------------- |
| **설정·검증 코드 우선** | CI의 결정론적 강제<br>문서 분량 축소 | 설정·검증 코드 유지 비용<br>의미 판단 영역의 미보장 |
| 모든 기준을 문서로      | 낮은 작성 비용                       | 준수 여부 판정 불가                                 |
| 모든 기준을 코드로      | 전부 기계 판정                       | 의미 판단 기준 표현 불가                            |
