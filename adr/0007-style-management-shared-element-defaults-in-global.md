# 0007. 스타일 관리. 공통 요소 기본값은 전역 스타일에

## Status

채택

## Context

weather-app 작업에서 가로 스크롤에 필요했던 스크롤바 숨김이 전역 스타일로 옮겨졌고(`58ee726`), [0005](0005-style-management-token-contract-and-exit-guardrails.md)는 전역 스타일이 토큰 이름의 계약만 정한다고 해 이 규칙은 한 도메인의 값으로 읽혔다. 검토 결과 스크롤바 숨김은 모든 도메인이 같이 쓰기로 했고, 문서 전체(`html`)의 스크롤바는 슬라이스 범위 밖이라 슬라이스에서 숨길 수 없다. 이 결정은 0005를 대체하지 않고, 전역 스타일이 정하는 범위를 모든 도메인에 같은 요소 기본값까지 넓힌다 (출처: Issue #186, Issue #189, 사용자 확인).

## Decision

- 모든 도메인에 같은 요소 기본값은 전역 스타일에 두고, 기본값과 다른 표시가 필요한 도메인은 슬라이스 안 요소를 그 요소의 유틸리티로 되돌리며, 문서 뷰포트의 기본값은 전역 스타일 변경으로만 바꾼다.

- 모든 도메인이 같이 쓰기로 한 요소 기본값(스크롤바 숨김)이 생긴 상황에서 그 기본값을 둘 곳을 정하는 문제를 해결해야 했다.
  전역 배치를 택하고 슬라이스별 배치는 택하지 않았다.
  문서 뷰포트까지 한 곳에서 적용과 슬라이스 간 중복 제거를 얻기 위해서이며, 기본값과 다른 도메인의 되돌림 부담, 모든 도메인의 스크롤 단서 상실, 문서 뷰포트의 도메인별 되돌림 불가를 받아들인다.

## Consequences

| 선택지          | 얻는 것                                                 | 잃는 것                                                                                                    |
| --------------- | ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **전역 배치**   | 문서 뷰포트까지 한 곳에서 적용<br>슬라이스 간 중복 제거 | 기본값과 다른 도메인의 되돌림 부담<br>모든 도메인의 스크롤 단서 상실<br>문서 뷰포트의 도메인별 되돌림 불가 |
