# 0004. 디렉토리 구조. FSD 유지

## Status

채택

## Context

이 저장소는 디렉토리 경로를 기계가 읽어 구조 규칙을 판정하려 하므로, 경로 규약이 외부에 명세되어 있고 린터가 검사할 수 있어야 한다. 챌린지는 계속 늘어나고, React만 쓰는 1인 개발이다. FSD와 기능 단위 모듈러 모놀리스를 같은 루브릭으로 두 평가자가 독립 채점한 결과, 가중 합계는 2.75 대 2.75, 2.90 대 2.45였다 (출처: 사용자 확인).

## Decision

- 디렉토리 구조는 FSD를 유지하고, 구조 규칙은 Steiger와 ESLint로 판정한다.

- 디렉토리 경로로 구조 규칙을 기계 판정해야 하는 문제를 해결해야 했다.
  FSD 유지를 택하고 모듈러 모놀리스는 택하지 않았다.
  외부 명세된 경로 규약, 기존 lint·CI 판정 유지, 이전 비용 없음을 얻기 위해서이며, 외부 방법론 학습 비용과 여러 곳의 챌린지 등록을 받아들인다.

## Consequences

| 선택지          | 얻는 것                                                           | 잃는 것                                           |
| --------------- | ----------------------------------------------------------------- | ------------------------------------------------- |
| **FSD 유지**    | 외부 명세된 경로 규약<br>기존 lint·CI 판정 유지<br>이전 비용 없음 | 외부 방법론 학습 비용<br>여러 곳의 챌린지 등록    |
| 모듈러 모놀리스 | 폴더 이름만으로 위치 파악                                         | 설정·문서 전면 수정<br>관례 규칙의 판정 수단 부재 |
