# 0001. 외부 API. Vercel Functions 중계

## Status

채택

## Context

앱은 정적 파일만 배포해서 외부 API를 브라우저에서 직접 부른다. 키가 필요한 API는 키가 빌드 산출물에 드러나고, CORS를 막은 API는 브라우저가 요청을 막는다. 앱은 이미 Vercel에 배포한다 (출처: 사용자 확인).

## Decision

- 키가 필요하거나 CORS를 막은 외부 API는 루트 `api/`의 Vercel Functions로 중계한다.

- 정적 배포 앱에서 키 노출과 CORS 차단 문제를 해결해야 했다.
  Vercel Functions 중계를 택하고 별도 서버 배포, 응답 고정, 챌린지 제외는 택하지 않았다.
  브라우저 코드의 키 비노출과 기존 Vercel 프로젝트에서의 함께 배포를 얻기 위해서이며, Vercel 플랫폼 종속과 로컬 함수 실행용 별도 환경을 받아들인다.

## Consequences

| 선택지                    | 얻는 것                                                         | 잃는 것                                               |
| ------------------------- | --------------------------------------------------------------- | ----------------------------------------------------- |
| **Vercel Functions 중계** | 브라우저 코드의 키 비노출<br>기존 Vercel 프로젝트에서 함께 배포 | Vercel 플랫폼 종속<br>로컬 함수 실행용 별도 환경 필요 |
| 별도 서버 배포            | 배포처 독립<br>실행 시간 제약 없음                              | 상시 실행 서버 별도 운영                              |
| 응답 고정                 | 서버 불필요<br>결정적인 화면 결과                               | 실제 데이터 표시 불가                                 |
| 챌린지 제외               | 추가 구조 없음                                                  | 선택 가능한 챌린지 감소                               |
