# 0001. 키가 필요하거나 CORS를 막은 외부 API는 Vercel Functions로 중계한다

## 상태

채택

## 배경

앱은 정적 파일만 배포해서 외부 API를 브라우저에서 직접 부른다. 키가 필요한 API는 키가 빌드 산출물에 드러나고, CORS를 막은 API는 브라우저가 요청을 막는다(근거: 사용자 확인).

## 비교한 대안

| 대안             | 버린 이유                              |
| ---------------- | -------------------------------------- |
| 별도 서버 배포   | 상시 실행 서버를 따로 운영하게 된다    |
| 응답 고정        | 챌린지가 실제 데이터를 보여주지 못한다 |
| 그런 챌린지 제외 | 고를 수 있는 챌린지가 줄어든다         |

## 결정과 근거

키가 필요하거나 CORS를 막은 외부 API는 루트 `api/`의 Vercel Functions로 중계한다.

- 이미 Vercel에 배포하고 있어 같은 프로젝트에서 함수를 배포한다.
- 키가 브라우저 코드에 드러나지 않는다.

## 재검토 조건

- 배포처를 Vercel에서 옮길 때
- 함수가 중계 외의 일(저장, 인증)을 해야 할 때
