# 0002. AI 통제. OMC 위 결정론적 구조

## Status

채택

## Context

OMC의 `tdd` 같은 절차는 프롬프트 수준이라 AI가 따를지가 비결정적이다. 이 프로젝트는 AI 도구를 만드는 능력이 아니라 외부 도구를 가져와 의도대로 통제하는 능력을 보이는 것이 목표다 (출처: 사용자 확인).

## Decision

- AI 개발 도구는 OMC를 가져다 쓰고, 지켜야 할 절차는 LLM 바깥의 코드(훅, 테스트, CI)로 강제한다.

- AI 개발 도구의 절차를 AI가 따를지 비결정적인 문제를 해결해야 했다.
  OMC + 결정론적 구조를 택하고 자체 AI 도구 제작, OMC 프롬프트 규칙만 사용은 택하지 않았다.
  도구 제작 비용 없음과 절차 준수의 기계 판정을 얻기 위해서이며, OMC 변경에 종속과 구조 유지 비용을 받아들인다.

## Consequences

| 선택지                   | 얻는 것                                      | 잃는 것                                    |
| ------------------------ | -------------------------------------------- | ------------------------------------------ |
| **OMC + 결정론적 구조**  | 도구 제작 비용 없음<br>절차 준수의 기계 판정 | OMC 변경에 종속<br>구조 유지 비용          |
| 자체 AI 도구 제작        | 도구 동작의 완전한 통제                      | 도구 제작·유지 비용<br>LLM 비결정성 미해결 |
| OMC 프롬프트 규칙만 사용 | 추가 구조 없음                               | LLM 비결정성 미해결                        |
